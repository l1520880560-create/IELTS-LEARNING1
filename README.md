## 这套练习册有什么

- **15 篇听力文本**：左栏英文原稿 + 右栏中文参考译文，A3 横双栏版式
- **真题式题型**：
  - Spot Dictation：短文听写，10 空，每空一词
  - Conversation：对话填词，一般不超过 3 词，常考时间、地点道路名称、细节信息
  - Interview & Lecture：访谈讲座，对错判断（T/F）+ 问答题，答案一般不超过 3 词
- **15 段美音音频**（`audio/`）：EnglishPod 风格，真人感、有情绪，重弱读/连读/语调标准，语速适中（A2 友好）；对话篇为男女双声
- **可点击交互词表**：正文中**红色 = 高频词**、**蓝色 = 基础答案词**，点击任意词弹出 **国际音标 + 中文释义 + 🔊发音**（浏览器 TTS）
- **可打印 PDF**（`pdf/`）：A3 横向双栏，每篇一页，红字重点词，含参考答案与做题技巧

## 数字复习模块（`numbers.html`）

基于何琼听力笔记数字考点 + 剑桥雅思 Section 1 真实出题手法设计的专项训练：

- **6 张规则速查卡**：年份 / 时刻 / 日期 / 金钱 / 号码 / 辨音陷阱，每条标注【笔记原文】【补充】
- **7 类单数字机打练习**：年份（1960–2025）· 非整点时刻（4:07）· 日期（2nd/June/2017）· 金钱（带单位，$3.59 / £120.80）· 航班/电话/邮编号码 · 纯数 01–200 · 分数；每类题库 70 题、随机抽 10，键盘直接输入即时判分（金额带单位 / 时间只认冒号 / 邮编不分大小写）
- **210 句场景实战**：医院、学校、车站等真实场景句子，听音填数字；三档递进——基础易错（s1–70）、进阶连读（s71–140）、**高难辨音（s141–210）**：连读制造辨音难度 + 信号词定位（but/actually/used to/now/not...it's/I mean/sorry）+ 陷阱多样化（8/9 近音、teen/ty、改口更正、条件假设、因果递进、一句三数字综合）
- **56 段生活对话**：剑桥 Section 1 笔记填空版式（信号词 / 同义替换 / 改口纠正 / 辨音干扰），男女双声美音整段播放，含 16 段数字密集对话
- **错题本**：答错自动收录，可反复重练
- **播放条**：可拖动进度、0.75–1.5× 变速（默认 1.2×，贴合真实语速）

**练习建议**：
1. 先看题，预测填空词性（名词/数字/日期/地名）
2. 播放该篇音频，完整听一遍做题
3. 对照右栏译文订正；点击红色/蓝色词复习音标与释义
4. 精听第二遍，注意重读词（通常是答案词）与连读弱读

**做题技巧提示**（各篇底部有针对性提示）：
- 填空答案通常是**重读**的词：时间、数字、地点、名称
- 注意转折信号词：but / however / actually / unfortunately（后文常是答案）
- 日期与数字注意拼写（September / October / second / pounds）
- 对话类注意人物关系与问答轮次，答案紧跟提问
