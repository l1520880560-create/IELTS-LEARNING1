# IELTS Listening Workbook · 雅思听力练习册（公派留学 / 访学备考）

一套面向 **A2 水平**学习者的雅思听力模拟练习册：**15 篇原创练习**（5 篇短文听写 Spot Dictation + 5 篇对话填词 Conversation + 5 篇访谈讲座 Interview & Lecture），全部文本由母语级英语编写，场景与剑桥雅思真题一致（住宿、图书馆、旅行、学术、地理、银行、餐饮、求职、娱乐、问路、动物、商业、科研、城市、健康）。

## 这套练习册有什么

- **15 篇听力文本**：左栏英文原稿 + 右栏中文参考译文，A3 横双栏版式
- **真题式题型**：
  - Spot Dictation：短文听写，10 空，每空一词
  - Conversation：对话填词，一般不超过 3 词，常考时间、地点道路名称、细节信息
  - Interview & Lecture：访谈讲座，对错判断（T/F）+ 问答题，答案一般不超过 3 词
- **15 段美音音频**（`audio/`）：EnglishPod 风格，真人感、有情绪，重弱读/连读/语调标准，语速适中（A2 友好）；对话篇为男女双声
- **可点击交互词表**：正文中**红色 = 高频词**、**蓝色 = 基础答案词**，点击任意词弹出 **国际音标 + 中文释义 + 🔊发音**（浏览器 TTS）
- **可打印 PDF**（`pdf/`）：A3 横向双栏，每篇一页，红字重点词，含参考答案与做题技巧

## 词汇覆盖

全套正文**100% 覆盖**两类目标词库：
- 雅思听力高频词汇：644 词（均匀分布在各篇）
- 剑桥雅思听力基础答案词：350 词（穿插重复出现）

## 使用方法

| 文件 | 用途 |
|---|---|
| `spot_dictation.html` | 短文听写篇（No.1–5），每篇开头有对应音频 |
| `dialogues.html` | 对话填词篇（No.6–10），男女双声对话 |
| `lectures.html` | 访谈讲座篇（No.11–15），T/F + 问答 |
| `pdf/` | 15 篇可打印练习册（A3 横双栏） |
| `audio/` | 15 段独立 MP3 音频 |

**练习建议**：
1. 先看题，预测填空词性（名词/数字/日期/地名）
2. 播放该篇音频，完整听一遍做题
3. 对照右栏译文订正；点击红色/蓝色词复习音标与释义
4. 精听第二遍，注意重读词（通常是答案词）与连读弱读

**做题技巧提示**（各篇底部有针对性提示）：
- 填空答案通常是**重读**的词：时间、数字、地点、名称
- 注意转折信号词：but / however / actually / unfortunately（后文常是答案）
- 日期与数字注意拼写（September / October / second / pounds）
- 对话类注意人物关系与问答轮次，答案紧跟提问
